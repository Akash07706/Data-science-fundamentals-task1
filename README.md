# Task 1 — Data Science Fundamentals
Mini-project: Exploratory analysis of a small synthetic student-performance dataset.

## Run
1. Install Python 3.10+.
2. In this folder run: `pip install -r requirements.txt`
3. Run: `python main.py`

The script inspects data types, missing values and duplicates; calculates descriptive statistics, mean, median, standard deviation and correlation; groups scores into performance bands; and saves a scatter plot.

The CSV contains fictional teaching data, not real student records. Correlation is descriptive and does not establish causation.
